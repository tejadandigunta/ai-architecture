Linear search checks one index at a time, so worst case it costs n comparisons — all 10, here. Binary search throws away half of what's left every round, so it costs about log₂ n comparisons — just 4. The gap widens fast: at 1,000,000 items, that's 1,000,000 vs. roughly 20.
